# 실제 파일로 교체해주세요

지금 이 폴더에는 미리보기가 깨지지 않도록 자동 생성한 자리표시자 이미지/음원이 들어있습니다.
배포 전에 **같은 파일명 그대로** 실제 파일로 덮어써주세요.

| 경로 | 용도 | 권장 사이즈 |
|---|---|---|
| `main-photo.jpg` | 첫 화면(TitleCard) 배경 사진 — 문구 없이 사진 한 장만 보이므로, 이름/날짜 문구가 필요하면 사진 자체에 디자인해서 넣어주세요 | 세로형, 960×1600 이상 |
| `invitation.png` | 손글씨/캘리그래피 이미지 (InvitationSection) | 투명 배경 PNG |
| `kakao.jpg` | 카카오톡 공유 시 보이는 썸네일 | 800×400 (2:1) |
| `map-preview.jpg` | 오시는 길 섹션 상단에 보이는 지도 스크린샷 (네이버지도/카카오맵에서 위치 검색 후 캡처) | 가로형 |
| `map-guide.jpg` | "약도 이미지 보기" 버튼을 누르면 뜨는 약도 | 세로형 |
| `bgm.mp3` | 배경음악 | mp3, 1~3분 루프 권장 |
| `gallery/1.png` ~ `gallery/15.png` | 갤러리 사진 15장 | 정사각형에 가까운 비율 권장 |

`groom.jpg` / `bride.jpg`는 신랑·신부 소개 섹션을 삭제하면서 더 이상 쓰이지 않아요. 그대로 둬도 사이트엔 영향 없습니다.

**참고**: `main-photo.jpg`, `kakao.jpg`, `map-preview.jpg`, `map-guide.jpg` 는 파일명에 `.jpg`가 들어있지만, 실제 파일이 PNG여도 이름만 저 형식으로 맞추면 정상 작동해요 (반대로 이 파일들도 `.png`로 이름 바꿔서 올리고 싶으시면 말씀해주세요 — 코드 한 줄씩만 바꾸면 돼요).

갤러리 파일 형식은 `src/data/wedding.ts` 의 `gallery.extension` 값으로 정해집니다 (지금은 `"png"`). 사진 장수를 15장보다 늘리거나 줄이고 싶다면 같은 파일의 `gallery.count` 값만 바꿔주면 됩니다.

이 안내 파일(`README-ASSETS.md`)은 실제 배포에는 영향이 없으니 지워도 됩니다.
